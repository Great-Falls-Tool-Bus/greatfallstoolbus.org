# Great Falls Tool Bus

A shared tool library on wheels for Lewiston-Auburn, Maine.

**This is a bus. The shop comes later :)**

## Where we are

We won the bus — the vehicle itself, not just the idea of one.

This repository is the member-tree application (`greatfallstoolbus.org`):
membership application intake, and the account/contribution/inventory system
that follows it (ADR 0014, `Great-Falls-Tool-Bus/meta`). The public
information site — mission, tools, how to get involved, project news — lives
in the separate `gftb-site` repository and is not part of this codebase
(single-product history, L72 Q3-A, 2026-08-21: the legacy marketing-tree
routes this repo used to serve directly are retired here in favor of that
split).

Membership application intake is not yet open for the public launch window.
